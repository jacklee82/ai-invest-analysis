# 차트인 가치 분석 설계 문서

## 1. 개요

### 1.1 목적
차트 진입(차트인) 곡의 가치를 정량적으로 분석하여 투자 의사결정에 활용

### 1.2 범위
- 차트 100위권 내 진입 기간 동안 발생한 수익 분석
- 차트인 주 수와 수익 간의 회귀 모델 구축
- 차트인으로 가장 많은 수익을 낸 곡 Top 10 분석

### 1.3 용어 정의
- **차트인 수익**: 차트 100위권 내 체류 기간 동안 발생한 모든 수익
- **차트인 주 수**: 차트 100위권 내 체류한 주(week) 수
- **차트인 가치**: 차트인 1주당 평균 수익 (천만원 단위)

## 2. 데이터 모델

### 2.1 현재 데이터 구조

#### 2.1.1 프로젝트 테이블 (`project`)
- `projectId`: 프로젝트 ID
- `projectName`: 프로젝트명 (곡명 가능)
- `businessType`: 사업 타입 (선급투자, 일반투자, OST, 음반)
- 기타 투자/회수 정보

#### 2.1.2 월별 현금흐름 테이블 (`cashflowMonthly`)
- `projectId`: 프로젝트 ID
- `yyyymm`: 년월 (YYYY-MM)
- `revenue`: 매출
- `cost`: 비용
- `profit`: 이익

### 2.2 필요한 데이터 확장

#### 2.2.1 차트 정보 저장 방식 (옵션 A: 별도 테이블)
```sql
CREATE TABLE chart_entry (
    chart_entry_id VARCHAR(255) PRIMARY KEY,
    project_id VARCHAR(255) NOT NULL REFERENCES project(project_id),
    chart_rank INTEGER NOT NULL, -- 1~100위
    week_date DATE NOT NULL, -- 해당 주의 시작일
    chart_type VARCHAR(50) DEFAULT '가요', -- 가요, OST 등
    created_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_chart_entry_project ON chart_entry(project_id);
CREATE INDEX idx_chart_entry_week ON chart_entry(week_date);
```

#### 2.2.2 차트 정보 저장 방식 (옵션 B: 프로젝트 메타데이터)
프로젝트 테이블에 차트 정보를 JSON/텍스트로 저장:
```typescript
// project 테이블에 추가
chartInfo: {
  totalChartedWeeks: number; // 총 차트인 주 수
  bestRank: number; // 최고 순위
  chartPeriods: Array<{
    startDate: string; // YYYY-MM-DD
    endDate: string;
    weeks: number;
  }>;
}
```

#### 2.2.3 추천 방식
**옵션 A (별도 테이블)**: 추천
- 차트 데이터가 상세할수록 정확한 분석 가능
- 주 단위 집계 및 추세 분석 용이
- 확장성 및 유지보수성 우수

**옵션 B (메타데이터)**: 간단하지만 분석 제한적

```typescript
// 의사코드
function calculateChartRevenue(projectId: string, chartPeriods: ChartPeriod[]) {
  let totalRevenue = 0;
  
  for (const period of chartPeriods) {
    // 차트인 기간 동안의 월별 현금흐름 합계
    const monthlyCashflows = getCashflowsByDateRange(
      projectId,
      period.startDate,
      period.endDate
    );
    
    totalRevenue += monthlyCashflows.reduce((sum, cf) => sum + cf.revenue, 0);
  }
  
  return totalRevenue;
}
```

#### 2.3.2 차트인 주 수 계산
```typescript
function calculateChartedWeeks(chartPeriods: ChartPeriod[]) {
  return chartPeriods.reduce((total, period) => {
    const weeks = calculateWeeksBetween(period.startDate, period.endDate);
    return total + weeks;
  }, 0);
}
```

## 3. 분석 기능 설계

### 3.1 기능 B: 차트인 가치 추정

#### 3.1.1 단순 평균 계산
```typescript
interface ChartValueEstimate {
  averageValuePerWeek: number; // 천만원 단위
  totalProjects: number;
  totalChartedWeeks: number;
  totalChartRevenue: number;
}

function calculateAverageChartValue(projects: Project[]): ChartValueEstimate {
  const chartData = projects
    .filter(p => p.chartInfo?.totalChartedWeeks > 0)
    .map(p => ({
      chartedWeeks: p.chartInfo.totalChartedWeeks,
      chartRevenue: calculateChartRevenue(p.projectId, p.chartInfo.chartPeriods),
    }));
  
  const totalChartedWeeks = chartData.reduce((sum, d) => sum + d.chartedWeeks, 0);
  const totalChartRevenue = chartData.reduce((sum, d) => sum + d.chartRevenue, 0);
  
  return {
    averageValuePerWeek: (totalChartRevenue / totalChartedWeeks) / 10_000_000, // 천만원 단위
    totalProjects: chartData.length,
    totalChartedWeeks,
    totalChartRevenue,
  };
}
```

### 3.2 기능 C: Top 10 차트인 수익 곡

#### 3.2.1 데이터 조회 및 정렬
```typescript
interface TopChartTrack {
  projectId: string;
  projectName: string;
  artist: string; // 기획사명 또는 아티스트명
  chartRevenue: number;
  chartedWeeks: number;
  averageRevenuePerWeek: number;
  bestRank: number;
}

function getTopChartTracks(projects: Project[], limit: number = 10): TopChartTrack[] {
  return projects
    .filter(p => p.chartInfo?.totalChartedWeeks > 0)
    .map(p => ({
      projectId: p.projectId,
      projectName: p.projectName,
      artist: p.companyName, // 또는 별도 아티스트 필드
      chartRevenue: calculateChartRevenue(p.projectId, p.chartInfo.chartPeriods),
      chartedWeeks: p.chartInfo.totalChartedWeeks,
      averageRevenuePerWeek: calculateChartRevenue(...) / p.chartInfo.totalChartedWeeks,
      bestRank: p.chartInfo.bestRank,
    }))
    .sort((a, b) => b.chartRevenue - a.chartRevenue)
    .slice(0, limit);
}
```
