# 대시보드 구현 설계 (신규 프로젝트)

## 1. 프로젝트 개요

### 1.1 목적
경영진(P1)을 위한 투자 현황 대시보드 구축. 한 화면에서 핵심 지표를 파악하고, 리스크를 즉시 확인할 수 있어야 함.

### 1.2 사용자
- **주 사용자**: 경영진 (P1)
- **부 사용자**: 사업관리팀 (P2)
- **접근 빈도**: 일 1회 이상
- **사용 시간**: 3-5분 내 핵심 정보 파악

### 1.3 핵심 요구사항
1. **한눈에 보기**: 총계 KPI 3-5개
2. **비교 분석**: 사업별, 월별 성과 비교
3. **리스크 조기 경보**: 경고 프로젝트 즉시 확인
4. **트렌드 파악**: 월별 추세 시각화
5. **성능**: 첫 화면 로딩 p95 < 500ms

## 2. 데이터베이스 스키마 분석

### 2.1 핵심 테이블

#### `project` (프로젝트 마스터)
- **주요 필드**:
  - `project_id` (PK)
  - `project_name` (UNIQUE, 데이터 키)
  - `company_name` (기획사명)
  - `contract_start_date` (계약 시작일)
  - `base_contract_months`, `extended_months` (계약 기간)
  - `initial_investment`, `additional_investment` (투자금)
  - `total_recouped` (총 회수금)
  - `business_type` (선급투자, 일반투자, OST, 음반)

- **계산 가능한 지표**:
  - 총 투자금 = `initial_investment + additional_investment`
  - 총 계약 기간 = `base_contract_months + extended_months`
  - 회수율 = `total_recouped / 총 투자금`
  - 경과 개월 = (현재일 - `contract_start_date`) / 30
  - 경과 비율 = 경과 개월 / 총 계약 기간
  - 계약 종료일 = `contract_start_date` + 총 계약 기간 개월

#### `cashflow_monthly` (월별 현금흐름)
- **주요 필드**:
  - `id` (PK)
  - `project_id` (FK → project)
  - `yyyymm` (YYYY-MM 형식)
  - `revenue_amount` (매출액)
  - `cost_amount` (원가)
  - `recoup_amount` (회수금)

- **집계 가능한 지표**:
  - 월별 총 매출, 총 원가, 총 회수금
  - 사업별 월별 매출/원가
  - 프로젝트별 누적 매출/원가
  - 월별 이익 = 매출 - 원가
  - 월별 이익률 = 이익 / 매출

#### `risk_flag` (리스크 평가)
- **주요 필드**:
  - `evaluated_id` (PK)
  - `project_id` (FK)
  - `evaluated_at` (평가 일시)
  - `is_warning` (경고 여부)
  - `recoup_ratio` (회수율)
  - `elapsed_ratio` (경과 비율)

- **경고 조건**: `elapsed_ratio > 0.5` AND `recoup_ratio < 0.5`

#### `chart_entry` (차트 진입 정보)
- **주요 필드**:
  - `chart_entry_id` (PK)
  - `project_id` (FK)
  - `chart_rank` (1~100)
  - `week_date` (주 시작일)
  - `chart_type` (가요, OST 등)

- **분석 가능한 지표**:
  - 차트인 주 수
  - 차트인 기간 동안 수익 (cashflow_monthly와 조인)

## 4. 위젯별 상세 설계

### 4.1 KPI 카드 행 (5개)

#### 4.1.1 누적 투자금
- **값**: `SUM(initial_investment + additional_investment)`
- **표시**: 원 단위 (억원 단위 자동 변환)
- **YoY**: 전년 동월 대비 증감률 (데이터 확보 시)
- **스타일**: 파란색 계열
- **클릭 동작**: 없음

#### 4.1.2 누적 회수금
- **값**: `SUM(total_recouped)`
- **표시**: 원 단위
- **YoY**: 전년 동월 대비 증감률
- **스타일**: 녹색 계열
- **클릭 동작**: 없음

#### 4.1.3 회수율
- **값**: `(총 회수금 / 총 투자금) × 100`
- **표시**: % (소수점 1자리)
- **YoY**: 전년 동월 대비 증감률
- **스타일**: 보라색 계열
- **클릭 동작**: 없음

#### 4.1.4 누적 매출
- **값**: `SUM(cashflow_monthly.revenue_amount)`
- **표시**: 원 단위
- **YoY**: 전년 동월 대비 증감률
- **스타일**: 청록색 계열
- **클릭 동작**: 없음

#### 4.1.5 리스크 건수
- **값**: 경고 조건 충족 프로젝트 수
- **조건**: `elapsed_ratio > 0.5` AND `recoup_ratio < 0.5`
- **표시**: 건수
- **스타일**: 빨간색 계열 (경고 색상)
- **클릭 동작**: `/risk` 페이지로 이동

**구현 우선순위**: P0 (최우선)

---

### 4.2 사업별 성과 비교

#### 차트 타입
- **메인**: 그룹 막대 그래프 (매출, 이익)
- **보조**: 선 그래프 (이익률, 이중축)

#### 데이터 구조
```typescript
{
  businessType: "선급투자" | "일반투자" | "OST" | "음반",
  revenue: number,  // 매출액
  profit: number,   // 이익액
  margin: number    // 이익률 (%)
}
```

#### 계산 로직
- **선급투자**: 이익 = `total_recouped - (initial_investment + additional_investment)`
- **일반투자**: 이익 = `SUM(revenue_amount) - SUM(cost_amount)`
- **음반**: 이익 = `SUM(revenue_amount) - SUM(cost_amount)` (또는 매입원가 활용)
- **OST**: 이익 = `SUM(revenue_amount) - SUM(cost_amount)`

#### 시각화
- X축: 사업타입 (4개)
- Y축(왼쪽): 금액 (매출, 이익)
- Y축(오른쪽): 이익률 (%)
- 범례: 매출, 이익, 이익률
- 색상: 사업타입별 고정 팔레트

**구현 우선순위**: P0

---

### 4.3 월별 추세

#### 차트 타입
- **메인**: 면적 차트 (매출)
- **보조**: 선 그래프 (이익률, 이중축)

#### 데이터 구조
```typescript
{
  yyyymm: "2024-01",
  revenue: number,
  profit: number,
  margin: number
}
```

#### 집계
- `cashflow_monthly`를 `yyyymm` 기준으로 그룹화
- `revenue = SUM(revenue_amount)`
- `profit = SUM(revenue_amount) - SUM(cost_amount)`
- `margin = (profit / revenue) × 100`

#### 시각화
- X축: 년월 (YYYY-MM)
- Y축(왼쪽): 매출액 (면적)
- Y축(오른쪽): 이익률 (선)
- 보조선: 전년 동월 값 (회색 점선, 데이터 확보 시)

**구현 우선순위**: P0

---

### 4.4 투자→회수 워터폴

#### 차트 타입
- 워터폴 차트

#### 데이터 구조
```typescript
{
  totalInvestment: number,  // 초기값
  totalRecouped: number,    // 증가
  profit: number           // 최종값
}
```

#### 계산
- `totalInvestment`: `SUM(initial_investment + additional_investment)`
- `totalRecouped`: `SUM(total_recouped)`
- `profit`: `totalRecouped - totalInvestment`

#### 시각화
- 3단계 워터폴
- 색상: 투자금(파란색), 회수금(녹색), 이익(회색/빨간색)

**구현 우선순위**: P1

---

### 4.5 Top 기획사 스캐터

#### 차트 타입
- 스캐터 차트 (버블)

#### 데이터 구조
```typescript
{
  companyName: string,
  totalInvestment: number,  // X축
  recoupRate: number,      // Y축 (%)
  totalRevenue: number,    // 버블 크기
  businessType: string    // 색상
}
```

#### 집계
- `project`를 `company_name` 기준으로 그룹화
- `totalInvestment = SUM(initial_investment + additional_investment)`
- `totalRecouped = SUM(total_recouped)`
- `recoupRate = (totalRecouped / totalInvestment) × 100`
- `totalRevenue = SUM(cashflow_monthly.revenue_amount)`

#### 시각화
- X축: 총 투자금
- Y축: 회수율 (%)
- 버블 크기: 총 매출
- 색상: 사업타입
- Top 20만 표시 (투자금 큰 순)

**구현 우선순위**: P1

---

### 4.6 리스크 현황

#### 차트 타입
- 도넛 차트 (전체 대비 경고 비율)
- 미니 라인 차트 (월별 경고 건수 추세)

#### 데이터 구조
```typescript
{
  totalProjects: number,
  warningProjects: number,
  warningRate: number,  // %
  monthlyTrend: Array<{
    yyyymm: string,
    warningCount: number
  }>
}
```

#### 계산
- 경고 조건: `elapsed_ratio > 0.5` AND `recoup_ratio < 0.5`
- `risk_flag` 테이블 활용 또는 `project` 계산

#### 시각화
- 도넛: 전체 / 경고 비율
- 미니 라인: 월별 경고 건수 추세 (12개월)

**구현 우선순위**: P0

---

### 4.7 계약 만기 예정

#### 차트 타입
- 히트맵 또는 타임라인

#### 데이터 구조
```typescript
{
  yyyymm: string,
  expiringCount: number,
  projects: Array<{
    projectName: string,
    companyName: string,
    expiryDate: string
  }>
}
```

#### 계산
- 계약 종료일 = `contract_start_date + (base_contract_months + extended_months) 개월`
- 월별 만료 예정 프로젝트 집계

#### 시각화
- 히트맵: 월별 만료 예정 건수
- 색상: 임박할수록 빨간색
- 클릭: 상세 목록 표시

**구현 우선순위**: P1
